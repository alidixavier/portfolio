# Alidiane Xavier — Portfolio

Portfolio profissional bilíngue (português/inglês), responsivo, feito em HTML, CSS e JavaScript.

## Publicação no endereço https://alidixavier.github.io/portfolio/

Este é um **Project site** do GitHub Pages. Para publicar corretamente no repositório `portfolio`:

1. Abra https://github.com/Alidixavier/portfolio
2. Extraia este ZIP no seu computador.
3. Envie os arquivos e a pasta `assets` diretamente para a raiz do repositório. Não envie a pasta externa `portfolio-project-site` e não deixe os arquivos dentro de outra pasta.
4. A estrutura na aba **Code** deve ficar assim:

   ```text
   portfolio/
   ├── index.html
   ├── styles.css
   ├── script.js
   ├── README.md
   └── assets/
       └── profile-placeholder.svg
   ```

5. Faça o commit das alterações na branch `main`.
6. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/(root)`. Salve.
7. Aguarde a publicação e acesse https://alidixavier.github.io/portfolio/.

Os caminhos dos arquivos do site são relativos (`styles.css`, `script.js` e `assets/...`), então funcionam no endereço de Project site `/portfolio/`.

## Foto profissional

A imagem atual é apenas um espaço reservado. Para substituí-la, envie sua foto para `assets/profile.jpg` e altere no `index.html` o caminho `assets/profile-placeholder.svg` para `assets/profile.jpg`.
